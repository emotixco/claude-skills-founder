# /founder:email-sequence moved

This file moved to [`skills/email-sequence/SKILL.md`](../skills/email-sequence/SKILL.md) in v2.0.0, when the repo became a Claude Code plugin.

Install v2 inside Claude Code:

```
/plugin marketplace add emotixco/claude-skills-founder
/plugin install founder@emotix
```

If you installed v1 by copying or symlinking this `commands/` folder, delete that copy first, or you will see every skill twice. The README has the details under [Install](../README.md#install).

When this file runs as a slash command: show the user the install steps above and stop. The old skill is no longer here.
